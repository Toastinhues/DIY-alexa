DIY Alexa ( if you have a spare broken phone or a Raspberry Pi )

# **Motive of this Project** <h2> tag

_There are a lot of broken phones or tech which are just not being used at all, so I decided to make something to help the cause by designing a simple yet clever Alexa-based device, taking advantage of all the resources of the phone or Raspberry Pi if you want a more custom and private Alexa_
> To Be Honest, I would seriously suggest using a Raspberry Pi only, as it's more beginner-friendly and on top of that if the phone has problems flashing the OS or eMMC failures (**as in my case**) the project will have to pivot away from a phone or it will take a lot more time>
